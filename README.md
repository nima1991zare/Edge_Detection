# Edge Detection (MATLAB)

Machine-vision coursework: classic edge detectors.
- **Built with:** MATLAB — `canny.m`, `prewitt.m`, `sobel.m`.
- **Run:** open each `.m` in MATLAB (or Octave) and run it against an input image; adjust the image path/threshold inside the script.
- Pure scripts — nothing to install beyond MATLAB/Octave.
